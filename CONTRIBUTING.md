# Katkıda bulunma

Node.js 24 veya üzerini kullanın. `npm ci`, `npm test` ve `npm run build` komutları değişiklikten önce ve sonra çalışmalıdır. Geliştirme için iki terminalde `npm run dev` ve `npm run dev:web` çalıştırın.

Yeni oyun adaptörleri yeteneklerini açıkça bildirmeli; desteklenmeyen işlem hata vermelidir. Oyuncu verisi ve yetki kontrolleri sunucu tarafında kalmalıdır. Gerçek SSH bilgisi, davet kodu, köprü tokenı veya `data/` dosyalarını commit etmeyin.

PR açıklamasında kullanıcıya görünen değişikliği ve doğrulama adımlarını belirtin. Yeni envanter sağlayıcıları için [köprü sözleşmesini](docs/BRIDGE.md) izleyin.
